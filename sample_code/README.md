# Sample Code Fixtures

This directory will hold small, safe, self-contained sample code fixtures for local testing of the RAG pipeline in **Phase 1: Local RAG**.

## Guidelines for Sample Fixtures:
- Only contain clean, safe, mock repository files (e.g., sample Java, Python, C source files).
- Used for testing code chunking, AST parsing, and retrieval without requiring live GitHub network calls.
- Never place actual production secrets, sensitive tokens, or unvetted scripts in this folder.
